把五级层级交给一条生灭过程

吴桐 · 赵睿 · 张文琦 · 吴梦豪

519 名学生的英语学习效率被聚成五级层级。层级不是标签，而是马尔可夫链的状态：向上跳的强度 λ 与向下跳的强度 μ 之比 ρ，就是"这个人正在变好还是变差"的量化。下面每一块都可以动手改参数，页面里的数字全部由 数据/web_data.json 现场重算。

01 / EVOLVE

让层级动起来

选一个人所在的层级，拉时间轴，看他的层级分布怎样从一根针摊开成整条链。状态空间是五级（第 1 层最高效、第 5 层最低效），λ+μ = c = 2.54 周⁻¹。

曲线是该起点在 t 时刻的层级分布 pk(t)；竖线是当前时刻。混合时间 8.4–9.3 周（论文表 15）——过了这个点，起点的信息基本被抹掉。

02 / INTERVENE

动作实验室：改一个旋钮，重估 519 个人

选一种动作、给一个每周学时，页面会用协变量系数 δ 把 519 位学生的标准化协变量整体平移，重算每个人的 ρ，再聚合成五层强度比与转移矩阵（时间跨度可切 1 / 4 / 8 / 16 周）。

灰点 = 不干预时的 ρ
转移矩阵 P(16 周)
行 = 起点层级列 = 终点层级（左→右：第 1→5 层）

16 周后各行已趋同（接近平稳分布），要看出层级差异请切到 1–4 周。

03 / ONE STUDENT

看一个人：S480 的 16 周

选一个学生：左边是「不干预」，右边是 02 里那个动作与投入。两张图共用 0–100% 的纵轴，拖动时间轴或点播放，同一条曲线的高度差就是这一动作对他个人的效果；绿色虚线是不干预时的同层均值。

04 / POPULATION

519 个 ρ 的形状

点一层筛选，直方图只统计那一层的个体；切到「施加当前动作」会按 02 里选中的动作与投入重算一遍。竖线 ρ = 1：左边的人正在往低层级漂，右边的人在往上走。柱高是“组内占比 / 组距”的密度，用全样本最大密度归一——55 人的层与 234 人的层因此可以直接比形状。
