把五级层级交给一条生灭过程

吴桐 · 赵睿 · 张文琦 · 吴梦豪

519 名学生的英语学习效率被聚成五级层级。层级不是标签，而是马尔可夫链的状态：向上跳的强度 λ 与向下跳的强度 μ 之比 ρ，就是"这个人正在变好还是变差"的量化。下面每一块都可以动手改参数，页面里的数字全部由 数据/web_data.json 现场重算。

01 / EVOLVE

让层级动起来

选一个人所在的层级，拉时间轴，看他的层级分布怎样从一根针摊开成整条链。状态空间是五级（第 1 层最高效、第 5 层最低效），λ+μ = c = 2.54 周⁻¹。

曲线是该起点在 t 时刻的层级分布 pk(t)；竖线是当前时刻。混合时间约 8.7–9.3 周——过了这个点，起点的信息基本被抹掉。

02 / INTERVENE

动作实验室：改一个旋钮，重估 519 个人

选一种动作、给一个每周学时，页面会用协变量系数 δ 把 519 位学生的标准化协变量整体平移，重算每个人的 ρ，再聚合成五层强度比与转移矩阵（时间跨度可切 1 / 4 / 8 / 16 周）。

灰点 = 不干预时的 ρ
转移矩阵 P(16 周)
行 = 起点层级列 = 终点层级（左→右：第 1→5 层）
03 / ONE STUDENT

看一个人：S480 的 16 周

换一个学生，曲线就是他"已经离开原层级"的累积概率。虚线是他所在层级的平均水平——同一个链，个体差异只来自一个 ρ。

个体同层均值跃层概率 50% 参考线
04 / POPULATION

519 个 ρ 的形状

点一层筛选，直方图会实时只统计那一层的 519 个个体之一部分；勾选动作后按该动作重算。竖线 ρ = 1：左边的人正在往低层级漂，右边的人在往上走。

05 / REPRODUCE

这些数字能被重跑出来

六个 R 脚本在 R 4.6.0 上从头执行全部 exit 0；数据/ 下的结果文件重跑后与入库版本逐字节一致，种子 20261121 全流程锁定。

数据是「标定重建」：原文未公开问卷，本文以 n=519、5 类、S480 效率 0.6771、单步 25.38% / 累计 43.97% 为锚点构造同构数据；结构性结论属「复现成立」，数值性结论属「在锚点约束下成立」。
